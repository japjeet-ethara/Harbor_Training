The repository at `/workspace/repo` contains the MIT-licensed Python titlecase implementation from ppannuto/python-titlecase, commit `42f43e2de55bf003b286c6f8e8d8b2d26676a167`. It applies title capitalization rules while treating small words, punctuation, names, and compounds specially. The behavioural reference is CPython 3.12.8, Unicode 15.0.0, with the optional `regex` package absent and all `titlecase()` arguments at their defaults.

Create a Go main package at the repository root. It must read UTF-8 titles from stdin, one record per LF-delimited line, and print the default Python `titlecase()` result for each record followed by LF. A CR immediately before an LF is part of the line delimiter. A final nonempty record without a delimiter must also be processed. An empty stream has no records. Empty records and all other characters and whitespace must be handled exactly. Records do not contain CR or LF within their title text.

Use only the Go standard library and your own source. `go build ./...` must succeed in `/workspace/repo`, and `go build -o /tmp/titlecase .` must produce the runnable program. Remove every `.py` file anywhere under the repository. Preserve the upstream license and attribution.

The result for each record must equal the pinned original Python function byte for byte. Automatic hidden checks award a weighted mean: build has weight 1, removal of Python files has weight 1, and exact behaviour has weight 4. The Python-removal check awards credit only when the build passes. Behaviour credit is the fraction of correctly matching hidden records; missing records, extra records, invalid framing, crashes, and timeouts lose credit. External Go modules are unavailable. The program is expected to terminate on the supplied records. Speed, memory optimization, and error-message wording are not otherwise graded.
