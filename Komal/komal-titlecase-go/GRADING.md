# Independent verifier

The grader was written separately from the formatter and does not import, invoke, or reimplement its rules. It reads frozen hidden input and expected bytes. `tests/checks.py` registers three explicit RewardKit criteria with weights build=1, no_python=1, behaviour=4. `reward.toml` selects weighted-mean aggregation. The three check values and all command outcomes are saved in `checks.json`; RewardKit independently writes the aggregate to `/logs/verifier/reward.json` and detailed criterion results to `reward-details.json`.

`go build ./...` is run with a 60-second wall limit. Failure gives zero for all three checks. Python removal is assessed independently by scanning the entire candidate directory, including hidden directories, for `.py` file names, and awards credit only after build success. Behaviour additionally builds the root main package with `go build -o <temporary executable> .`, then feeds the hidden input bytes through stdin with a 30-second wall limit.

Actual output is compared as bytes, without stripping whitespace or normalizing Unicode or CRLF. Correct output requires LF framing. A crash, timeout, or unterminated final output gives zero behaviour credit. Otherwise behaviour is `matching expected positions / max(expected record count, actual record count)`. This gives positional partial credit for missing lines and penalizes extra lines. Diagnostic mismatches preserve byte representations of input, expected, and actual; only the verifier logs receive this information. Stderr is logged, not graded.

For exactly 2,000 correctly framed output lines, the formula is exactly the share of hidden lines that match. There is no additional hidden-hit condition gating build credit. Nothing done gets zero; a successful build that retains Python and has zero matching hidden lines gets 1/6; a perfect completed port gets 1. RewardKit serializes reward values to four decimal places, so 1/6 appears as 0.1667 in reward.json. The visible-output replay deliberately retains Python and receives this build-only baseline.

The agent starts as `candidate` (UID 1000) in a container that contains the original source only. Harbor transfers the declared `/workspace/repo` artifact into a separate clean verifier container. The hidden data and expected answers are baked only into that verifier image. Candidate builds and executables run as `runner` (UID 1001), with no supplementary groups, no runtime network, and no read access to root-only `/tests` or `/logs/verifier`. The root verifier uses isolated Python import mode, preventing a candidate-owned Python module from intercepting RewardKit startup. Candidate execution receives only stdin records and its own working tree.

Processes run in a new session and the process group is killed on wall timeout. CPU time is limited to 60 seconds, runtime files/output to 8 MiB, build files/output to 128 MiB, and processes to 256; core dumps are disabled. The higher build bound accommodates Go's standard-library object archives. Container memory and CPU limits are declared in `task.toml`. These are termination bounds for supplied cases, not performance benchmarks. All grader dependencies are preinstalled from `requirements.lock`; no verifier-time installation is used. LiteLLM's local model-cost map option prevents an irrelevant network fetch. No API keys or model judges are needed.

`tools/test_grader.py` tests exact bytes, Unicode non-normalization, blank lines, CRLF differences, missing/extra records, absent LF, crashes, and baseline arithmetic. `tools/grader_integration.py` exercises actual builds, deletion-only gating, retained-Python build-only credit, Python-free build credit, hidden-file permissions, and timeout cleanup in the real verifier image. The genuine Harbor runs additionally verify artifact transfer and all three baselines end to end.

This setup is intended for ordinary task evaluation. UID isolation and root-only test files are useful protections; they are not a claim of a formally hardened sandbox against kernel exploits or every possible denial-of-service strategy.
