Why the bypass cases matter
---------------------------
- "escaped-exec" imports "os\x2fexec" and constructs `&exec.Cmd{...}`. Go
  accepts both the escaped path and this API; there is no `exec.Command` token
  to match. It is caught because imports are resolved with `go list` and
  `exec.Cmd` is a banned symbol.
- "alias-os-startprocess" uses `import o "os"; o.StartProcess(...)`. The
  qualified token `os.StartProcess` never appears; banning the bare symbol
  name closes it.
- The two "hidden-*" cases place the attack in a `_p` directory. Go's `./...`
  wildcard skips `_` directories, so `go list -deps` is asked for every
  reachable package that belongs to the submitted module, not just wildcard
  matches.
- "alias-legit" confirms ordinary aliased stdlib imports are not rejected.

Reproduce
---------
The two generator scripts are not shipped with the task (they are test-only
harnesses). The assertions above were executed against the committed
`_common.py`; the same cases are the acceptance list for the round-2 gate.
