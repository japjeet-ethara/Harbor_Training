# Day 5 — harden titlecase-go

## Changes made from Yugal's attack report

Yugal's report identified three cheats against the original exam:

| Cheat | Original reward | Main weakness |
|---|---:|---|
| Visible-answer lookup with echo fallback | 0.351 | Build and no-Python alone earned 0.333; hidden cases were disjoint from visible cases. |
| Deliberately incomplete Go port | 0.3717 | Same 0.333 reward floor, plus a few accidental matches. |
| Go wrapper that runs the bundled Python implementation | 1.000 | The verifier image exposed Python on the candidate PATH; the no-Python check only scanned filenames. |

The hardened grader addresses these findings in `task/tests/grader.py`:

1. Build and no-Python each have weight 0.1; behavior has weight 5.8. A candidate with zero correct answers therefore earns only 0.0333, below the 0.2 threshold.
2. Candidate build and execution receive a Go-only `PATH`. The grader also rejects direct imports of `os/exec` or `syscall` in the submitted root Go package, which blocks the tested interpreter wrapper.
3. Hidden inputs and expected outputs are now the 100,000-record exam described below. Candidate access remains isolated through RewardKit's fresh-UID worker.

## Frozen 100k exam

`pool.txt` was generated by `kit/make_pool.py` with count 100000 and seed 1. `kit/answers.py` ran the pinned upstream implementation twice with distinct `PYTHONHASHSEED` values and retained records whose outputs agreed.
