# Day 5 exam measurements

## Frozen exams

The old exam is the original 2,000-line hidden set, preserved in `old-exam/`.
The graded exam is a 100,000-title pool generated by `kit/make_pool.py`.
`kit/answers.py` froze the answers twice using Python 3.14.2 and standard
`re` (`REGEX_AVAILABLE = False`); each freeze kept 100,000 of 100,000 titles,
and the input and answer files were byte-identical.
