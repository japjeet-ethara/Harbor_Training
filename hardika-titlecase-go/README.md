# Harbor titlecase-go

Submitted by Hardika (hardika@ethara.ai).

Port the default Python titlecase function to a Go stdin/stdout command. The starter workspace is the upstream Python project. The oracle installs a standalone Go interpreter for the capitalization rules. Harbor grades a copy of the submitted workspace in a separate, offline verifier.

## Setup

Use Docker with Linux containers, Harbor 0.26.0, Bash and Python 3.12 or newer for Harbor tooling. The two Docker builds fetch pinned base images and Python wheels. The running containers use no network. See [Windows and WSL](docs/WINDOWS-WSL.md) for setup from Windows.

From the extracted project directory, run the standalone image checks and all three Harbor baselines.

```bash
bash tools/run_harbor.sh
```

The script makes a fresh directory with commands, logs, job JSON and the replay task. To run a single baseline, use `harbor run -p . --env docker -a oracle` or replace `oracle` with `nop`. Use the replay task generated by `tools/replay_task.py` as the path and select the oracle agent to run the visible-answer replay.

Use the Go interpreter directly from `solution/go`.

```bash
cd solution/go
go build -o /tmp/titlecase .
printf '%s\n' 'the chronicle of the coast' | /tmp/titlecase
```

## Reference and verification

Use CPython 3.12.14 with Unicode 15.0.0 and regex 2026.11.15 in VERSION0 mode. The vendored upstream commit and MIT notice are in [NOTES.md](NOTES.md). Install the optional regex dependency with `python -m pip install regex==2026.11.15` in that Python environment. The verifier has its own hashed Reward Kit lockfile.

With Go 1.23.12 and the reference Python environment available, run the independent checks from the project root.

```bash
bash tools/validate.sh
```

See [ACCEPTANCE.md](ACCEPTANCE.md) for Section 18 evidence, [evidence/README.md](evidence/README.md) for observed results and provenance, and [architecture](docs/ARCHITECTURE.md) and [dataset](docs/DATASET.md) for implementation details.
